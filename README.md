One original one-line one-star review, written by a house cat about its human, for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty: he opens a tin, the cat comes running, he feeds the DOG first. The cat filed a complaint with the dog. The dog ate it. (120 characters, 120 bytes.)

## Run it

```sh
node main.ts
```

It writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Two runs are byte-identical (sha256 `0a28ba03a3795287b8cb6dd73ff76b5990d5c0c6c773f23484e5472b7e6e69e1`).
